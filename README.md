# kWeather

A weather app for Pebble watches, drawn by hand to look its best.

- **Now:** a big icon, the temperature, the high and low, how it feels, and when it will rain.
- **Rain and temperature:** the next 24 hours on one chart: a temperature curve over hourly rain bars.
- **Week:** 7 days with icons and a coloured temperature range.

Up and Down change page, Select refreshes. It uses your phone's location and [Open-Meteo](https://open-meteo.com) (free, no account).

**Install:** [kWeather.pbw](https://github.com/gkerherve/kWeather/releases/latest/download/kWeather.pbw)
